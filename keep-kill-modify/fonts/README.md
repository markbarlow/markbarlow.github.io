# Fonts

Both are self-hosted so the page makes no third-party request — it never calls
Google, which matters for a survey that promises anonymity.

| File | Family | Licence |
|---|---|---|

| `crimson-pro-latin.woff2`, `crimson-pro-latin-italic.woff2` | [Crimson Pro](https://fonts.google.com/specimen/Crimson+Pro) by Jacques Le Bailly | SIL Open Font License 1.1 |

Latin subset only, taken from the Google Fonts CDN. The OFL permits
redistribution like this. Full licence text:
<https://openfontlicense.org/open-font-license-official-text/>

The page declares `Georgia, 'Times New Roman', serif` as the fallback stack, so
it stays readable if the font files are ever missing.
