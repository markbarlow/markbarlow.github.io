Ravelin's view ends hereIt saw two tool calls. It cannot see, trace or recall where this data goes next.

The server is Ravelin's.
It is Acme's responsibility to protect the data returned.

Ravelin controls

  • Authenticating callers & scoping access to Acme's data only
  • Restricting permissions based on the authenticated user's role
  • Which tools exist and what each can return
  • Logging and rate-limiting the calls it receives

Acme is responsible for

  • Who in Acme can connect, and with which roles and permissions
  • Which AI providers see the data during the chat, and the terms that govern it
  • Everything that happens once the data is in the chat: copies, shares, other agents & MCPs
  • Storage, retention, DPIA & legal basis for the PII retrieved from Ravelin
